模块一：数据转换提取配置

功能名称

数据报表导出模板管理、可视化图表导出模板管理、导出任务执行与辅助功能。

用户场景

数据治理专员或业务人员需要按照政务数据报送、业务分析、大屏展示等要求，将单位、部门、用户及业务数据按固定格式导出为报表或可视化图表；在大数据量、敏感数据、定时/异步场景下，需要分页、脱敏、进度、通知和历史记录支撑。

业务规则

  • 模板名称在同一范围内唯一，必填字段校验通过后方可保存，保存后默认启用。
  • 导出字段选择、数据脱敏规则、分页参数、导出格式均属于“模板配置项”。
  • 预览数据量限制在合理范围，敏感数据默认脱敏展示。
  • 大文件导出采用异步任务，任务完成后保留导出历史，支持查询、下载、重新导出。
  • 所有导出操作记录操作日志。

输入

  • 用户权限身份信息。
  • 模板基础信息（名称、描述、格式、类型）。
  • 字段选择、脱敏字段、分页大小、过滤条件。
  • 导出任务触发指令。

输出

  • 报表/图表导出模板列表。
  • 导出任务信息（任务 ID、进度、状态、预计剩余时间）。
  • 导出的文件（Excel/CSV/图片/PDF）。
  • 站内信/系统通知。
  • 操作日志记录。

异常处理

  • 无权限：提示“暂无权限”并禁用操作入口。
  • 数据校验失败：高亮错误字段并提示具体原因。
  • 导出任务失败：记录失败原因，通知提交人，支持重新导出。
  • 系统异常：记录日志并提示“操作失败，请联系管理员”。

验收标准

  • 支持导出模板的创建、编辑、复制、删除、批量删除、版本管理。
  • 模板配置包含导出字段选择、数据脱敏、分页设置、导出格式。
  • 导出流程包含预览、进度展示、系统通知。
  • 导出历史记录独立页面，可查询、下载、重新导出。
  • 敏感数据在预览和导出文件中均脱敏。

模块二：数据查询

功能名称

多类型索引管理（单位索引、部门索引、用户索引、待办事项索引、群组索引、网络电话索引、活跃度索引、日程索引、应用索引、行为索引）。

用户场景

业务人员在日常工作中需要快速检索组织人员、业务对象和行为记录，例如按单位编码查找单位、按姓名查找用户、按时间段查找活跃记录、按关键词查找待办或日程，并基于查询结果开展数据治理或统计分析。

业务规则

  • 索引数据来源于各业务系统，按实体类型分别维护，禁止跨实体混用字段。
  • 支持编码精确/自动补全、名称模糊查询、关键词查询、自定义时间范围查询。
  • 查询结果按用户权限范围过滤，敏感字段脱敏展示。
  • 支持索引的新增、编辑、删除、批量删除、版本管理、统计查看。
  • 记录用户查询历史，支持复用历史条件。

输入

  • 用户权限身份信息。
  • 实体类型选择（单位/部门/用户/待办/群组等）。
  • 查询条件：编码、名称、关键词、状态、标签、时间范围。

输出

  • 索引列表（含编码、名称、关键属性、数据来源、标签、版本、状态、更新时间）。
  • 索引详情/编辑信息。
  • 统计结果与查询历史。

异常处理

  • 无权限：隐藏操作按钮并提示“暂无权限”。
  • 查询超时：提示“查询超时，请缩小查询范围”。
  • 数据不存在：列表展示空状态。
  • 系统异常：记录日志并提示“操作失败，请联系管理员”。

验收标准

  • 覆盖 10 类索引实体，每类索引独立字段和过滤条件。
  • 支持精确查询、模糊查询、关键词查询、自定义时间查询。
  • 列表支持分页，每类索引默认 20 条。
  • 新增/编辑/删除/版本/统计操作完整可用。
  • 查询历史可记录、复用、清空。

原型元素映射

顶部 Tab“单位索引/部门索引/用户索引/其他索引”实体类型切换

模块三：数据过滤

功能名称

多维度数据过滤查询（单位基本信息、部门基本信息、行政区划信息、业务条线信息、组织架构信息、时间范围信息、地理位置信息、区域编码信息）。

用户场景

用户在进行数据治理或业务分析时，需要按不同维度组合筛选数据，例如查询某行政区划下的单位、某业务条线涉及的部门、特定时间范围内的活跃用户、指定地理范围内的对象等。

业务规则

  • 八个维度分别提供独立的过滤项，用户可在同一页面切换维度。
  • 每个维度支持多条件组合查询、关键词查询、名称查询、自定义时间范围查询。
  • 查询结果默认按相关性或更新时间排序。
  • 保存用户查询记录，支持一键复用历史条件。

输入

  • 维度选择。
  • 过滤条件：编码、名称、关键词、行政区划、业务条线、时间起止、经纬度/半径、区域编码等。
  • 用户权限身份信息。

输出

  • 符合条件的记录列表及命中数量。
  • 查询历史记录。

异常处理

  • 无权限：提示并禁用查询。
  • 条件格式错误：高亮提示，例如时间范围倒置。
  • 查询超时：提示缩小范围。
  • 系统异常：记录日志并提示管理员。

验收标准

  • 覆盖 8 类维度，每类维度过滤项完整。
  • 支持多条件组合、关键词、名称、自定义时间查询。
  • 查询历史可查看、复用、清空。

原型元素映射

原型元素需求条目

顶部八个维度 Tab维度切换
各维度过滤条件区对应维度的查询条件
查询结果列表过滤结果展示
“查询历史记录”按钮/弹窗历史条件复用

模块四：数据模型管理

功能名称

统计模型管理（模型新增、编辑、删除、状态控制、版本管理、指标公式配置）。

用户场景

数据分析人员需要定义“用户活跃度”“部门协同度”等统计指标，为态势感知图表和大屏提供计算依据。

业务规则

  • 模型编码唯一，不可重复。
  • 统计维度支持日、周、月多选。
  • 指标公式可配置，保存前需语法校验。
  • 模型支持启用/禁用，禁用后不再参与计算。
  • 修改模型生成版本记录，支持查看历史版本。

输入

  • 模型编码、名称、描述。
  • 统计维度（日/周/月复选）。
  • 指标公式、状态。

输出

  • 模型列表。
  • 模型计算结果。
  • 版本历史记录。

异常处理

  • 编码重复：提示“模型编码已存在”。
  • 公式校验失败：高亮公式输入框并提示错误。
  • 无权限：禁用保存/删除按钮。

验收标准

  • 支持模型新增、编辑、删除、查询。
  • 统计维度支持多选。
  • 模型状态可启用/禁用。
  • 版本历史可查。

原型元素映射

原型元素需求条目
左侧菜单“数据模型管理”模块入口
模型列表模型查询与展示
“新增/编辑统计模型”弹窗模型信息、统计维度、指标公式
统计维度复选框日/周/月维度选择
状态开关/下拉启用/禁用控制

模块五：数据图表管理

功能名称

可视化图表配置与展示（图表类型选择、数据源绑定、样式配置、预览、导出）。

用户场景

领导或业务人员需要通过折线图、柱状图、饼图等直观查看态势指标，并支持将图表导出为图片用于汇报材料。

业务规则

  • 图表必须绑定已存在的统计模型或数据源。
  • 支持折线、柱状、饼图、面积图等常用类型。
  • 图表配置实时预览，预览数据与最终展示一致。
  • 图表支持导出为 PNG/JPG 图片。

输入

  • 图表名称、类型、数据源/统计模型。
  • 维度、指标、颜色、标题等样式配置。
  • 导出指令。

输出

  • 图表展示。
  • 图片文件。
  • 图表配置记录。

异常处理

  • 数据源无效：提示“数据源不存在或已禁用”。
  • 无权限：隐藏图表配置入口。
  • 导出失败：提示重新尝试。

验收标准

  • 支持常见图表类型。
  • 图表与数据一致，无变形。
  • 可导出图片。

原型元素映射

原型元素需求条目
左侧菜单“数据图表管理”模块入口
图表配置 Tab图表类型、数据源、样式
图表预览区实时预览
“导出图片”按钮图片导出

模块六：通知公告管理

功能名称

通知公告发布与管理。

用户场景

系统管理员需要向指定范围的用户发布系统通知、维护公告、政策更新等。

业务规则

  • 公告发布前支持草稿保存和预览。
  • 支持按组织范围、角色范围设置接收人。
  • 支持设置有效期和置顶。
  • 发布后用户在站内信/通知中心可见。

输入

  • 公告标题、内容、类型。
  • 接收范围、有效期、置顶标志。

输出

  • 公告列表。
  • 站内信通知。
  • 阅读记录。

异常处理

  • 必填项缺失：高亮提示。
  • 发布失败：提示原因并允许重新发布。

验收标准

  • 支持公告新增、编辑、发布、撤销、删除。
  • 支持按范围和有效期发布。
  • 用户可查看已发布公告。

模块七：日志管理

功能名称

系统日志审计（操作日志、登录日志、查询日志、导出日志、日志保留策略）。

用户场景

安全审计员或管理员需要追踪用户的操作行为、登录行为、查询行为和导出行为，满足政务系统审计合规要求。

业务规则

  • 日志内容不可篡改，保留期限可配置。
  • 支持按操作类型、时间范围、用户、模块等条件检索。
  • 日志支持导出为文件备查。
  • 超出保留期限的日志按策略自动归档或清理。

输入

  • 日志检索条件。
  • 日志保留策略配置。

输出

  • 日志列表。
  • 日志导出文件。
  • 审计报告。

异常处理

  • 无审计权限：隐藏日志入口。
  • 日志导出失败：提示重试。

验收标准

  • 覆盖操作、登录、查询、导出日志。
  • 支持多条件检索和导出。
  • 保留期限可配置。

模块八：参数管理

功能名称

系统参数配置（运行参数、保留期限、默认分页、通知开关等）。

用户场景

业务规则

输入

输出

  • 参数列表。
  • 生效的系统配置。

异常处理

  • 参数值格式校验失败：高亮提示。
  • 无权限：禁用编辑。

验收标准

  • 支持参数查询、编辑。
  • 变更留痕。

模块九：系统对接

功能名称

对接“赣政通”平台信创版底座（接口统计、接口分析、同步频率、接口适配、接口日志、日志分类、权限认证）。

用户场景

系统需要与“赣政通”底座平台进行数据同步和接口调用，管理员需要监控接口健康度、配置同步策略、查看调用日志并管理接口认证。

业务规则

  • 接口调用需经过认证，认证信息加密存储。
  • 同步频率可配置，支持定时和手动触发。
  • 接口适配规则可配置，用于字段映射和格式转换。
  • 接口调用日志分类存储，支持按类型、时间、状态检索。
  • 失败接口支持告警和重试。

输入

  • 接口配置、认证信息、同步策略。
  • 适配规则、日志检索条件。

输出

  • 接口调用统计和分析报告。
  • 同步结果。
  • 接口日志和告警。

异常处理

  • 接口超时/失败：自动重试并记录失败原因。
  • 认证失效：提示更新认证信息。
  • 同步冲突：按优先级或人工确认处理。

验收标准

  • 统计、分析、同步频率、适配、日志、日志分类、认证 7 个子模块完整可用。
  • 接口调用可监控，日志可检索。
  • 认证和同步策略可配置。
